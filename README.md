# osu! Beat Sound（ビート音アプリ）

[English README](README_en.md)

osu!を **NM（NoMod）** でプレイ中に、曲のビートに合わせて好きな音（NCのキック音など）を鳴らす、メトロノームのアプリです。
osu!本体には一切触らず、[tosu](https://github.com/KotRikD/tosu) から曲の再生位置を受け取って、音を鳴らすだけです。

> 非公式のツールです。osu!やtosuの開発元とは関係ありません。利用は自己責任でお願いします。
> マルチプレイやランクマッチなど、他の人と競う場面での使用はおすすめしません（詳しくは下の「注意」）。

## かんたんな使い方（exe版・おすすめ）
1. **Releases** から `osu_beat_sound_windows.zip` をダウンロードし、**「すべて展開」**します（zipの中から直接は動きません）。
2. [tosu](https://github.com/KotRikD/tosu) を用意し、tosuとosu!を起動します。
3. `sounds` フォルダに音声ファイルを入れ、`osu_beat_sound.exe` をダブルクリックします（Pythonは不要です）。
4. 画面の「●」が緑（接続OK）になれば準備完了。譜面をプレイすると、ビートに合わせて音が鳴ります。

## Python版で使う場合（ソースコードから）
- Windows 10 / 11、Python 3.10 以上（インストール時に「Add python.exe to PATH」にチェック）
- 展開したフォルダで、黒い画面（アドレスバーに `cmd`）を開いて実行します。

      python -m pip install -r requirements.txt
      python nc_beat.py

## 音声ファイルの入れ方
音声ファイルは付属していません。ご自身で用意して、`sounds` フォルダに次のどれかの名前で入れます。ないものは鳴りません（1つだけでもOK）。

| 役割 | ファイル名の例 |
|---|---|
| キック | `kick.wav` / `nightcore-kick.wav` |
| クラップ | `clap.wav` / `nightcore-clap.wav` |
| ハット | `hat.wav` / `nightcore-hat.wav` |
| フィニッシュ | `finish.wav` / `nightcore-finish.wav` |
| 数え声 (任意) | `beat1.wav` 〜 `beat8.wav`（`count1.wav` / `1.wav` でも可）。入れると、1拍ごとに 1・2・3・4 の順で鳴ります（kick / clap の代わり） |

拡張子は wav / ogg / mp3 / flac が使えます。

## 画面の見かた
- **ジャケット・譜面名**: 選択中の譜面の背景画像と、譜面名・アーティスト名・難易度名が出ます。背景の色は、譜面の画像に合わせて変わります。
- **音量・タイミング**: 再生バーの位置のスライダーです（タイミングはマイナスで遅く、プラスで早く鳴ります）。
- **中央の再生／一時停止**: ビート音のON／OFF。
- **⏮ ／ ⏭**: BPM倍率を1段階ずつ下げる／上げる（x0.5 ⇔ x1 ⇔ x2）。例: 160BPMの譜面でノーツが320で並んでいるときは、⏭でx2にします。
- **左のボタン**: 拍子の切り替え（AUTO・4/4・3/4・5/4・6/4・7/4）。
- **右の「♪」**: 鳴らす音の設定（kick / clap / hat / finish / 数え声 のON/OFFと試聴、「曲選択画面でも鳴らす」）。
- **右上の「●」と「•••」**: tosuとの接続状態（緑=接続OK、黄=接続中、赤=未接続）。「•••」からは、Setting（言語・テーマ・アクセントカラー・フォント・常に手前に表示・プレイ中は後ろへ隠す・自動起動・tosuの場所など）、接続の詳細、フルスクリーン（F11）、終了が開けます。

設定はウィンドウを閉じるときに `config.json` へ保存されます。本物のNCモッドをつけているときは、二重に鳴らないよう自動で止まります。

## 変拍子（3/4・5/4・7/4など）
- 譜面が3/4や7/4などを指定している場合は、自動でその拍子に合わせて鳴ります。
- 譜面は4/4のままで曲が変拍子のときは、**左のボタン（拍子）** で手動指定できます。
- 初期の鳴らし方は、1・3・5拍目=kick、2・4・6拍目=clap、裏拍=hat、小節の頭=finish です。奇数拍子では、次の小節頭のkickと続かないよう、最後の拍をclapにします。
- `config.json` の `patterns` で、拍子ごとの鳴らし方を変えられます（数字は、1小節を8分音符で数えた位置）。

      "patterns": { "3": {"kick": [0], "clap": [2, 4], "hat": [1, 3, 5], "finish": [0]} }

## リズムのパターンを変える
`config.json`（アプリを閉じて編集）の `pattern_4_4` を編集します。1小節を8分音符8個（0〜7）として、鳴らす位置を指定します。
例: キックを毎拍に鳴らす → `"kick": [0, 2, 4, 6]`

## 言語（Language）
Setting の「言語」で、日本語と英語を切り替えられます。他の言語は、`lang_template.json` をコピーして翻訳し、`lang` フォルダに `es.json` のような名前で入れてください。

## exeを自分で作る
`build_exe.bat` をダブルクリックすると、`dist\osu_beat_sound.exe` ができます。GitHubでは、タグ（例: `v1.1.0`）を付けると、Actionsが自動でexe入りのzipを作ります。

## うまくいかないとき
| 症状 | 対処 |
|---|---|
| tosuが「接続できません」 | tosuを先に起動する |
| 読込済み音が「なし」 | ファイル名と拡張子（`clap.wav.wav` のような二重拡張子に注意）を確認し、「サウンドを再読み込み」を押す |
| 音が鳴らない | 曲の「状態」が `play` になっているか確認。♪の試聴で鳴るかも確認する |
| 音が二重に鳴る | このアプリを2つ起動していないか確認する |
| 音がずれる | 「タイミング」スライダーで調整 |
| exeが起動しない / 削除される | zipを「すべて展開」してから起動する。ウイルス対策ソフトの誤検知なら、「許可」と除外設定をするか、Python版を使う |
