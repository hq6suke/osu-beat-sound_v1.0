# osu! Beat Sound（ビート音アプリ）

NM（NoMod）のままプレイ中に、曲のビートに合わせて好きな音（NCのキック音など）を鳴らすアプリです。
osu!本体には一切触らず、tosuから曲の再生位置を受け取って音を鳴らすだけです。

## 必要なもの
- Windows 10 / 11（64bit）
- osu!（stable）
- [tosu](https://github.com/KotRikD/tosu)（osu!の情報を取得するツール）
- 鳴らしたい音声ファイル（wav / ogg / mp3）※付属していません。ご自身で用意してください

Pythonのインストールは**不要**です。

## 使い方
1. zipを**必ず展開**します（右クリック →「すべて展開」）。zipの中から直接exeを開くと動きません。OneDrive内ではなく、デスクトップなど分かりやすい場所がおすすめです。
2. `sounds` フォルダに、音声ファイルを入れます（下の「音声ファイルの入れ方」参照）。
3. tosuとosu!を起動します。
4. `osu_beat_sound.exe` をダブルクリックします。小さなウィンドウが開きます。
5. 「tosu」が **接続OK** になっていれば準備完了です。osu!で曲をプレイすると、ビートに合わせて音が鳴ります。

初回は、Windowsの警告（「WindowsによってPCが保護されました」）が出ることがあります。「詳細情報」→「実行」を押してください。

## 音声ファイルの入れ方
`sounds` フォルダに、次のどれかの名前で入れます。ないものは鳴りません（1つだけでもOK）。

| 役割 | ファイル名の例 |
|---|---|
| キック | `kick.wav` / `nightcore-kick.wav` |
| クラップ | `clap.wav` / `nightcore-clap.wav` |
| ハット | `hat.wav` / `nightcore-hat.wav` |
| フィニッシュ | `finish.wav` / `nightcore-finish.wav` |

拡張子は wav / ogg / mp3 が使えます。

## 使いやすくする設定（画面の下のほう）
- **常に最前面に表示**: osu!の上にこのウィンドウを重ねたまま使えます
- **Windows起動時に自動で起動する**: パソコンを起動すると、自動でこのアプリが立ち上がります
- **tosuを自動で起動する**: tosuが起動していなければ、このアプリが起動します。初回だけ「tosu.exeの場所を指定」で場所を教えてください（tosuのフォルダに、このアプリを置いても自動で見つかります）
- **tosuをダウンロード**: tosuの配布ページが開きます

## 画面の見かた
- **音量**: 音の大きさ
- **タイミング**: 音が合わないときの調整です。マイナスで遅く、プラスで早く鳴ります
- **BPM倍率**: x2 にするとBPMの2倍で、x0.5 にすると半分で鳴らします（例: 160BPMの譜面でノーツが320で並んでいるとき）
- **鳴らす音**: 音ごとのON/OFFと、▶での試聴
- **曲選択画面でも鳴らす**: チェックを入れると、曲選択中にも鳴ります
- **サウンドを再読み込み**: 起動後にsoundsの中身を変えたときに押します

設定はウィンドウを閉じるときに `config.json` へ保存されます。
本物のNCモッドをつけているときは、二重に鳴らないよう自動で止まります。

## リズムのパターンを変える
`config.json` を開き、`pattern_4_4` を編集します。1小節を8分音符8個（0〜7）として、鳴らす位置を数字で指定します。
例: キックを毎拍に鳴らす → `"kick": [0, 2, 4, 6]`
編集は、アプリを閉じた状態で行ってください。

## うまくいかないとき
| 症状 | 対処 |
|---|---|
| 「ファイルにウイルスまたは望ましくない可能性のあるソフトウェアが含まれている」と出る | zipを**展開せず、zipの中から直接**起動していないか確認する。必ず「すべて展開」してから、展開したフォルダ内のexeを起動する |
| exeを右クリック →「プロパティ」に「許可する」のチェックがある | チェックを入れて「OK」を押してから、もう一度起動する |
| exeが勝手に削除・隔離される | ウイルス対策ソフトの誤検知です。Windowsセキュリティの「保護の履歴」から「許可」し、このフォルダを除外に追加する。止められる場合は、Python版（GitHubのソースコード）でも使えます |
| exeが起動しない / すぐ消える | ウイルス対策ソフトに止められていないか確認する。展開したフォルダから起動しているか確認する（zipの中から直接は不可） |
| tosuが「接続できません」 | tosuを先に起動する |
| 読込済み音が「なし」 | ファイル名と拡張子（`clap.wav.wav` のような二重拡張子に注意）を確認し、再読み込みを押す |
| 音が鳴らない | 曲の「状態」が `play` になっているか確認。▶ボタンで試聴できるかも確認する |
| 音が二重に鳴る | このアプリを2つ起動していないか確認する |
| 音がずれる | 「タイミング」スライダーで調整 |
